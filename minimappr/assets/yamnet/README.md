# Bundled YAMNet model

This directory contains the TensorFlow SavedModel published as
`https://tfhub.dev/google/yamnet/1`, downloaded on 2026-07-16. It is a
project asset rather than a TensorFlow Hub cache so runtime classification and
drone-head training work without a network request.

that license text.
